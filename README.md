# Valle Aventura — sitio web

Sitio público de las cabañas Valle Aventura (Las Trancas, Pinto).
Publicado con GitHub Pages en https://valleaventura-chile.com

- `index.html` — página de escritorio, con calendario de disponibilidad y flujo de reserva
- `movil.html` — versión para teléfono
- `support.js` — runtime de Claude Design (carga React desde `vendor/`, sin CDN externo)
- `uploads/` — imágenes optimizadas a WebP
- `CNAME` — dominio propio

Las imágenes originales pesaban 43 MB; aquí van en 2,6 MB sin pérdida visible.
